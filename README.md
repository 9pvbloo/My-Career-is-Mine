# My Career Is Mine.

An experimental interactive web experience about instinct, movement, autonomy and choosing your own path.

The horse acts as the central visual metaphor for freedom, force and forward motion.

> No predefined tracks.  
> No borrowed timelines.

## Tech Stack

- Vite
- TypeScript
- Three.js
- GSAP
- ScrollTrigger
- Lenis
- GLSL
- CSS

## Development

Install dependencies:

```bash
npm install
```
